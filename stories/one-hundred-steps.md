# 故事 5 · One Hundred Steps!（一百级台阶！）· 第 5 章 · v1 正文

> 场景：晴天的山路（石阶、木平台 deck、旧水井 well、大石头、蛛网）→ 半山大雾 → 山顶小屋（书桌 desk、炒锅 wok）与日落  
> 角色：Mia（主角，服装固定）、Mom；新角色：狐狸 Red Tip（红毛白尾尖，守山带路狐）、守山奶奶 Nan、小老鼠 Rat、蚂蚁队  
> 结构：立目标（自己数完一百级）→ 让路给蚂蚁 → 数到五十歇脚 → 唰唰声、红尾巴、晃动的蛛网（被跟踪？）→ 井边打水，小老鼠指路 → 狐狸露脸眨眼就跑 → 七十级起雾，腿疼想放弃 → 雾里白尾尖带路 → 数到一百登顶 → 谁住在小屋？→ 反转：狐狸是奶奶的带路狐 → 吃锅面、搭帐篷  
> 篇幅：24 页 · 每页英文 ≤ 11 词 · 一般现在时 · 画面不写字（路牌只画小屋和数字 100）
