# 故事 4 · The Big Tug!（沙漠大拔河）· 第 4 章 · v1 正文

> 场景：晴朗白天的沙漠（沙丘、仙人掌、绿洲、沙蜥洞口杂物堆）  
> 角色：Mia（主角，服装固定，衣服始终干净）、Dad、Mom、宠物母鸡 Hen（唯一的鸡）；胖嘟嘟橘色大沙蜥（凶萌）及小沙蜥宝宝；Sis、Ben 不出场  
> 结构：出游 → Hen 睡在包上 → 沙蜥卷走水和包（连 Hen）→ 叽叽声伏笔 → 爸爸伤腿、妈妈留下 → 米娅独自勇敢走向洞口 → 发现杂物堆（礼物盒/球棒/手套/旧布）→ 口香糖粘牙 → 球棒击沙球、手套接水瓶 → 旧布绳拔河，爸妈来帮 → 赢了但沙蜥难过 → 小沙蜥口渴 → 分水成朋友 → 驮全家出沙漠  
> 篇幅：26 页 · 每页英文 ≤ 11 词、≤ 50 字符 · 一般现在时 · 画面不写字（礼物标签只印大字母 G）
